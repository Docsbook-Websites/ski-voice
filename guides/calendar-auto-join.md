# Calendar auto-join

Sending your agent manually works once. For a standup that happens every morning, connect your calendar instead.

## How it works

Connect Google Calendar in SKI. From then on, SKI sends your agent into the meetings you have marked, either as a participant or as a silent notetaker, right on time. Recurring series are handled as a series, so you set it up once.

## The one requirement

The meeting's project has to be connected and active. Auto-join sends *your agent* into the call, and an agent that is not running in a live project has nothing to send. See [Multi-project routing](../concepts/multi-project.md) for keeping several projects live at once.

## Choosing the mode

The same two modes as a manual send apply: a live participant that speaks and answers, or a silent notetaker that only listens. Pick per meeting, based on whether you want the agent to contribute or only to remember.

## What you get afterwards

The same as a manual send: a speaker-tagged transcript and written notes with decisions and action items, waiting in Transcripts by the time you look.
