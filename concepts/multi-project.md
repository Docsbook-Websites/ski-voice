# Multi-project routing

One widget, several projects. Bind as many repos as you want, even across different coding agents, and address whichever one you are thinking about.

## Connect several at once

Each connection is the same two steps: install the skill for that agent once, then type `ski` in the session for that project. Claude Code in one repo and Codex in another can both be live at the same time.

## Switching

Click the project name on the widget to switch. What you say next routes to that project.

## A voice per project

Each connected project answers in its own voice. In practice this matters more than it sounds: when you are not looking at the screen, the voice is how you know which repo just told you the build is green.

## Which projects can act

A project has to be connected and active for anything to reach it. That also applies to [calendar auto-join](../guides/calendar-auto-join.md), where the meeting's project must be live for the agent to be sent.
